Java Backend Practice Projects

This repository contains multiple Java backend projects built for learning and practicing core concepts of Java and backend development. Each project focuses on specific topics such as OOP, data structures, design patterns, JDBC, and layered architecture (Controller–Service–Model).

🎯 Purpose

The main goal of this repository is to:

Strengthen Core Java fundamentals

Practice Object-Oriented Programming (OOP)

Understand project structure used in real-world backend applications

Learn layered architecture (Controller, Service, Model)

Prepare for backend development and interviews
